How It Works

Six-Stage Processing Pipeline

From raw pixel to interactive AR — every step is real computation happening in your browser.

📤
Image Ingestion

Your image is decoded into a raw pixel buffer using the Canvas API. Width and height are validated and the image tensor is prepared for analysis.

Canvas API · FileReader
🔬
Luminance Depth Extraction

Per-pixel depth is computed using the ITU-R BT.601 luminance formula: 0.299R + 0.587G + 0.114B. Brighter pixels are treated as nearer to the camera.

BT.601 · Float32Array
🌊
Box-Filter Smoothing

Configurable smoothing passes reduce high-frequency noise from the raw depth map, producing organic gradients that create natural-looking 3D topography.

9-tap Box Filter · Multi-pass
📐
Mesh Tessellation

A plane geometry is subdivided into thousands of quads. Each vertex is displaced along the Z-axis by its sampled depth value, building a true 3D surface mesh.

Three.js · PlaneGeometry
🤖
AI Object Detection

Claude Vision AI analyses your image to identify objects, estimate their screen positions as UV coordinates, and assign confidence scores and depth estimates.

Claude Vision · JSON
🏷️
Spatial AR Label Anchoring

UV coordinates are converted to 3D world positions on the mesh surface. Labels are rendered as floating HTML elements that track their 3D anchor points in real-time as you orbit.

CSS2D · World Coords
Capabilities

Built on Real Technology

No faking, no placeholders — every feature is backed by genuine computation.

🧮
Real Pixel-Level Depth

Depth is computed from every single pixel using the standard luminance formula. Resulting depth values drive actual vertex displacement in Three.js geometry.

ITU-R BT.601 Luminance
🏷️
Spatial 3D Labels

Labels float directly on top of detected objects — anchored to actual 3D coordinates on the mesh surface. They track and reposition as you orbit the scene.

CSS2DRenderer · World Space
🔺
Tessellated Mesh

Up to 128×128 quads subdivide the plane, each vertex physically displaced by depth — creating a genuine topographic 3D surface from any 2D photo.

Three.js · WebGL 2
🎛️
4 View Modes

Switch between Textured (your photo on the mesh), Depth Map (coloured by depth), Wireframe (topology visible), and Normal Map views live.

Live Mode Switching
🤖
AI Scene Understanding

Claude Vision analyses your photo to detect objects with confidence scores, UV coordinates, category labels, and estimated depth — then anchors them to 3D space.

Claude Sonnet Vision
🔒
Privacy First

All depth computation and 3D rendering runs entirely in your browser. Your image is never uploaded to any server except for the optional AI detection step.

Local · WebGL · Canvas
